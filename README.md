# Shaikh Qamar Abbas - 3D Scroll-Driven Portfolio

A modern, high-performance developer portfolio featuring a butter-smooth 3D can scroll animation synchronized with portfolio sections (Hero, About, Skills, Projects, and Contact).

## 🚀 Features

- **Butter-Smooth 3D Scroll Animation**: Dual-stage frame interpolation (Lenis smooth momentum scrolling + requestAnimationFrame LERP) rendering 300 sequential frames on HTML5 Canvas.
- **Glassmorphism UI**: Frosted dark glass cards with glowing ambient accents and backdrop blur.
- **100% Fully Responsive**: Fluid layouts, adaptive typography, and animated mobile navigation drawer for smartphones, tablets, and ultra-wide screens.
- **Offline & Zero Build Step**: Pure HTML5, modern CSS, and vanilla JavaScript with Lenis bundled locally.

## 🛠️ Tech Stack

- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **HTML5 Canvas API**
- **Lenis Smooth Scroll**

## 🌐 Live Preview

Clone the repository and run:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
